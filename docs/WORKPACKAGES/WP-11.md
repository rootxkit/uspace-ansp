# WP-11: `console-restrictions`

Branch `feat/WP-11-console-restrictions`. Milestone N-M1. Owns `web/`
(the app shell, BFF routes, i18n, the restrictions pages, the adapters
page, the `web` CI job's contents). Depends on WP-3 (OpenAPI → types),
WP-2 (auth contract), WP-5 (restriction operations). WP-12 adds the
picture, inbox, audit and switches to the same app.

The console renders. It holds no business logic, no geometry library,
no database and no NATS client (`00 §6`, `06` T12). Every number it
shows comes from the API with its units; every judgement (containment,
validity) is the API's answer.

## What to build

- `web/` Next.js App Router, TypeScript `strict`, Tailwind, shadcn/ui
  through `@rootxkit/uspace-ui`, MapLibre GL through the kit's map
  components; `ka` and `en` message catalogues from day one (every string
  through i18n; a lint rule fails a hard-coded user-facing string);
  branding (name, logo, colours) from a config bundle read at build
  time from environment, never from the repo.
- Package manager: `pnpm`, `packageManager` pinned in `package.json`,
  `pnpm install --frozen-lockfile` everywhere (M34).
- Types: `pnpm run types` runs the kit's `uspace-ui-gen-api`
  (`openapi-typescript`) on `../api/openapi.yaml` into
  `web/src/api/types.gen.ts` (committed; `generate-check` covers it);
  a typed fetch client over them; no hand-written API type (lint rule
  and the generated header). The kit's `Problem` type (`errors:
  [{field, reason}]`, `truncated`) is what the form kit renders (M28).
- BFF (`app/_bff/*` route handlers only, three routes, M22): `login`
  (password → `mfa` pending), `mfa` (TOTP → sets the **`uspace_session`**
  cookie `HttpOnly`, `Secure`, `SameSite=Strict` and the `uspace_csrf`
  cookie, M21), `logout`, and a proxy that forwards the cookie as a
  bearer to `api` for REST calls with the `X-CSRF-Token` double-submit
  header; no ticket route, nothing else in the BFF. WebSocket streams
  connect directly to the same origin with the cookie through the
  kit's `useFeed` / `live` client (gap 19, decided); a `4401` close is
  rendered as "signed out, sign in again". Session display reads the
  kit's `sessionClaimsUnverified` (`sub`, `roles[]`, `realm`, `exp`,
  M20).
- Fonts through the kit via `next/font/local`; the kit's CSP
  (`connect-src 'self'`, `font-src 'self'`, `worker-src blob:`); the
  basemap from `/basemap/` on the same origin (served by the
  deployment's Caddy from the shared volume, M38); no third-party tile
  or font request, ever (a Playwright assertion lists every request
  host).
- Pages:
  - Sign in with MFA enrolment flow (first login shows the TOTP QR from
    the API's enrolment response).
  - Restrictions list: state, window, U-space airspace, version,
    delivery state per channel (`CISP: published v3 at T` / `not yet
    published since T` / `DSS: written` / `pending since T`), alarms;
    live through `/v1/restrictions/stream` (console frame: the kit's
    `live` client dispatches on `schema`; `console/status/v1` drives
    the status bar, M29).
  - Restriction editor on the map: draw a polygon or a circle, enter
    lower and upper limits with the reference (`AMSL` / `WGS84`; `AGL`
    shown as unavailable with the API's reason), window, reason text in
    `ka` and `en`, U-space airspace selected from the API's list; the
    API's validation problems rendered by field; the chain proposal for
    long windows shown and confirmed; plan / activate / extend / end /
    cancel with confirmation dialogs stating what will be sent to whom.
  - Restriction detail: versions, the ED-318 feature as JSON, the F3548
    reference, the delivery log, the events.
  - Restriction requests: list, accept (opens the editor pre-filled),
    decline with reason.
  - Adapters: configured, running, silent since T, disabled by whom and
    why (B-11), counters, last frame.
- Empty states say why (`no restrictions`, `CIS projection stale: age
  400 s`, `signed out`), never a blank map.
- Playwright smoke against a mocked API (MSW or the generated client's
  stub): sign in with MFA, plan a restriction, activate it, see the
  delivery state change on the stream.
